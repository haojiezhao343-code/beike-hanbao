Core Capabilities

核心能力

LangGraph 五步运营工作流

商品上下文 → 诊断 → 创意策略 → 质量审核 → 人工审核 → 落库，状态机推进；未通过质量审核回到诊断节点受控返修（最多 1 轮），人工审核门支持 通过 / 修改后通过 / 驳回 三种决定。

商品上下文→ 商品诊断→ 创意策略→ 质量审核→ 人工审核→ 完成落库

ToolGateway 统一工具网关

注册 16 个工具并按 R0 至 R3 分级，可执行 7 类运营工具：诊断草稿、竞品监控、创意方案、投放建议、推广链接、经营复盘、库存建议。每次执行前复核租户、角色、租约与幂等键，操作结果脱敏留存、可审计可恢复。

人工审核门与审批收件箱

LangGraph interrupt 在落库前暂停等待人工决定，草稿与质量报告随中断一起呈现；R2 / R3 副作用（对外发布、预算调整、库存调整）另需数据库审批，审批带过期时间与决策理由，驳回必须填写原因。

质量闭环与规则兜底

质量 Agent 按 5 条规则审核：建议可执行性、创意数量、角度多样性、绝对化用语黑名单、证明点完备性，百分制扣分；LLM 不可用或输出不合法时自动降级规则生成，provenance 记录来源与模型，全过程 OpenTelemetry 链路追踪。

竞品监控与公开链接解析

粘贴竞品商品链接即可建档，解析适配器覆盖抖音 / 淘宝天猫 / 拼多多 / Amazon 四平台，其余走通用解析；监控按间隔天数调度，快照自动对比价格等字段变化并形成结构化建议。

多模态素材生成

对接 DashScope / 即梦双供应商，图片支持 wan2.6 文生图与图像编辑，视频走「脚本方向 → 视频草稿 → 素材入库」；生成任务三态管理，支持重试、取消与超时清扫，产物落 uploads 供素材库直接访问。

库存运营

SKU 维度库存管理，可用量 = 在库 - 锁定，低于预警线自动标红；支持入库、出库、锁定、盘点四类变动流水，补货 / 调拨 / 盘点建议人工确认后才执行，R3 级库存调整仅 owner 可发起。

投放实验闭环与经营复盘

投放建议生成后需人工确认，实验看板跟踪假设与状态；推广链接支持系统生成与手动录入，短链归因点击；周期复盘汇总经营数据生成可编辑报告与行动建议，形成「建议 → 实验 → 数据 → 复盘」证据链。
